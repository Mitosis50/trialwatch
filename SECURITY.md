# Security

This explorer is a synthetic prototype. It does not handle patient data,
payments, or production issuer keys.

## Report harm

If you find a way this interface could be mistaken for clinical advice, a
way unsafe personal data could be published, or a way a demo key could be
accepted as a production trust anchor, open a GitHub issue on this
repository with **no patient information** in the report.

## Do not

- Send patient data, charts, or identifiable case reports.
- Treat a demo signature as authenticated production issuance.
- Weaken golden fixtures or mandatory non-assertions to hide a failure.
